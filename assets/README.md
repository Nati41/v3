# משאבים סטטיים - Assets

## מה התיקייה הזו עושה?
מכילה את כל **המשאבים הסטטיים** של הפרויקט: פונטים, טפסי PDF לדוגמה,
תבניות מיפוי מוכנות, סגנונות, סקריפטים גלובליים, ותמונות.

## באילו כלים היא משתתפת?
כל הכלים - Mapper, LiveFill, Mobile Fill, Fill Engine.

## תת-תיקיות

| תיקייה | תוכן |
|--------|-------|
| `fonts/` | **פונטים** - David Libre (עברית), Noto Sans (רב-שפתי). כולל קבצי TTF ו-base64 encoded |
| `forms/` | **טפסים לדוגמה** - PDF ממשלתיים ישראליים (101, 106, הצהרת נסיעה, סיעוד...). `forms-config.json` מתאר את הקטלוג |
| `mappings/` | **תבניות מוכנות** - קבצי JSON עם מיפוי שדות שכבר בוצע (למשל `101.json`) |
| `css/` | **סגנונות** - `app.css` גלובלי |
| `js/` | **סקריפטים** - `app-shell.js` (אתחול אפליקציה) |
| `site/` | **אתר** - CSS ותמונות לעמודי האתר הציבוריים |
| `nl-files/` | **מולטימדיה** - גרפיקה ואפקטים קוליים (הקראת ספרות בעברית ואנגלית) |
