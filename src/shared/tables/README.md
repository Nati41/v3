# מודל טבלאות משותף - Tables

## מה התיקייה הזו עושה?
מממשת את **מודל הנתונים והממשק של טבלאות** שמשותף בין Mapper ו-LiveFill.
טבלה = קבוצת שדות חוזרים (למשל: רשימת ילדים עם שם + ת.ז. + תאריך לידה).

## באילו כלים היא משתתפת?
- **Mapper v3** - הגדרת טבלאות בזמן מיפוי
- **LiveFill** - מילוי נתוני טבלאות

## מי קורא לה?
- `TableRegionManager.js` (Mapper core) - הגדרת אזורי טבלה
- `fill-engine.js` - מילוי שורות טבלה
- `livefill-ui.js` - ממשק מילוי טבלאות

## מתי היא פעילה?
כשיש טבלאות בטופס.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `tableModel.js` | **מודל נתונים** - מבנה טבלה: headerBBox, sampleRowBBox, עמודות, שורות |
| `tableUI.js` | **ממשק טבלאות** - רינדור טבלאות בממשק המשתמש |
| `tableOverlay.js` | **שכבת טבלה** - אוברליי ויזואלי שמציג את גבולות הטבלה על ה-PDF |
| `tableStepController.js` | **בקר צעדים** - מנהל זרימת הגדרת טבלה צעד-אחרי-צעד |
| `tableValidatorWrapper.js` | **ולידציה** - בדיקת תקינות הגדרת טבלה |
