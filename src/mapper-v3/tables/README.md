# ניהול טבלאות - Tables (Stub)

## מה התיקייה הזו עושה?
מכילה את **בקר הטבלאות הישן** שהוחלף במערכת חדשה.
כיום זה stub (שלד ריק) שמייצא ממשק ריק לצורך תאימות לאחור.

## באילו כלים היא משתתפת?
**Mapper v3** - תאימות לאחור בלבד.

## מי קורא לה?
מודולים ישנים שעדיין מייבאים `TableFlowController`. לא משפיע על תפקוד.

## מתי היא פעילה?
לא פעילה בפועל. המערכת החדשה היא `core/TableRegionManager.js`.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `TableFlowController.js` | **Stub** - מייצא אירועים ריקים וצעדים ריקים. גיבוי מלא: `TableFlowController.js.backup` |
| `index.js` | נקודת כניסה |
