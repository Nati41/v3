# ממשק משתמש - UI

## מה התיקייה הזו עושה?
מכילה את כל **רכיבי הממשק** של כלי המיפוי: דיאלוגים, מסכים, סרגל צד,
מסך ברוכים הבאים, טעינת שדות, סקירת שדות, ועוד.

## באילו כלים היא משתתפת?
**Mapper v3** בלבד.

## מי קורא לה?
- `MapperCore.js` - מאתחל את ה-UI
- `EventBus` - אירועים מפעילים דיאלוגים ומסכים

## מתי היא פעילה?
תמיד כשה-Mapper פתוח. דיאלוגים נפתחים לפי צורך.

## קבצים מרכזיים

### ממשק ראשי
| קובץ | תפקיד |
|------|--------|
| `GuidedMappingUI.js` | **ממשק מיפוי מונחה** - מנהל את הזרימה: תבנית → מיפוי → ולידציה |
| `SidebarController.js` | **סרגל צד** - רשימת שדות, חיפוש, ניהול |
| `AutoAdvanceController.js` | **התקדמות אוטומטית** - עובר לשדה הבא אחרי מיפוי מוצלח |

### מסכי כניסה
| קובץ | תפקיד |
