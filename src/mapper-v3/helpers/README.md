# עוזרים - Helpers

## מה התיקייה הזו עושה?
מכילה **פונקציות עזר** לכלי המיפוי, בעיקר עבור בחירת שמות קנוניים לשדות.

## באילו כלים היא משתתפת?
**Mapper v3** - בממשק מיפוי שדות.

## מי קורא לה?
- `NameConfirmDialog.js` - דיאלוג אישור שם שדה
- `GuidedMappingUI.js` - ממשק מיפוי מונחה

## מתי היא פעילה?
כשמשתמש בוחר שם קנוני לשדה.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `CanonicalSelector.js` | **בורר שמות קנוניים** - מספק רשימת שמות סטנדרטיים (id_number, first_name, phone...) עם תוויות בעברית, מקובצים לפי קטגוריה |
