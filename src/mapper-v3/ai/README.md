# אינטגרציית AI

## מה התיקייה הזו עושה?
מספקת **חיבור ל-AI** (Claude של Anthropic) לצורך ניתוח אוטומטי של טפסים:
זיהוי שדות, שמות קנוניים, הקשר סמנטי, וניתוח מבנה.

## באילו כלים היא משתתפת?
- **Mapper v3** - ניתוח תבנית ואינטליגנציית שדות
- **מצב ניסיוני** - זיהוי שדות מציור פיזי (דרך ReverseMappingAI)

## מי קורא לה?
- `MapperCore.js` - מפעיל ניתוח AI
- `GuidedMappingUI.js` - מציג תוצאות AI למשתמש
- `FieldIntelligenceStore.js` - שומר תוצאות AI

## מתי היא פעילה?
רק כשהמשתמש מפעיל ניתוח AI (לא אוטומטי). דורש מפתח API.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `AIService.js` | **שירות AI מרכזי** - תקשורת עם Claude API / OpenAI. מודל ברירת מחדל: claude-sonnet-4. Singleton: `aiService` |
| `template-analyzer.js` | **פרומפטים לניתוח תבנית** - שולח תמונת PDF ל-AI, מקבל מבנה שדות מזוהה |
| `field-intelligence-prompt.js` | **פרומפטים לאינטליגנציית שדות** - שם קנוני, הקשר, פורמט, סוג נתון |
| `field-intelligence-schema.js` | **סכמת JSON** (v2) - מגדיר את מבנה הנתונים הסמנטיים. סוגי נתונים: ISRAELI_ID, PERSON_NAME, PHONE, DATE... |

## עיקרון חשוב
> נתוני AI הם **סמנטיים בלבד** - שם, הקשר, פורמט.
> אין בהם קואורדינטות, מספרי עמוד, או מידע ויזואלי.
> ההפרדה הזו מאפשרת לעדכן AI בלי לפגוע במיפוי הפיזי.
