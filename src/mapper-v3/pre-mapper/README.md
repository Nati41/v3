# עיבוד מקדים - Pre-Mapper

## מה התיקייה הזו עושה?
מטפלת ב**ייבוא נתונים חיצוניים** לתוך ה-Mapper:
קריאת קבצי JSON מ-AI/OCR חיצוני, וזיהוי אוטומטי של טבלאות בנתונים המיובאים.

## באילו כלים היא משתתפת?
**Mapper v3** - בשלב טעינת תבנית / ייבוא.

## מי קורא לה?
- `MapperCore.js` - בעת ייבוא קובץ JSON
- `StateManager.js` - SmartTableDetector בעת ניתוח שדות מיובאים

## מתי היא פעילה?
רק בזמן ייבוא נתונים. לא פעילה בזמן מיפוי רגיל.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `UnifiedImportAdapter.js` | **מתאם ייבוא** - ממיר JSON חיצוני (AI/OCR) לפורמט הפנימי של ה-Mapper. מנרמל bbox, מייצר ID חדשים, משמר מקור |
| `SmartTableDetector.js` | **זיהוי טבלאות חכם** - מזהה דפוסים חוזרים בשדות: child1_name, child2_name → טבלה "child" עם עמודה "name". מינימום: 2 שורות, 2 עמודות |
| `index.js` | נקודת כניסה - ייצוא המודולים |
