# שכבת תוויות - Label Overlay

## מה התיקייה הזו עושה?
מציגה **שכבה ויזואלית של תוויות שדות** מעל ה-PDF.
כשהמשתמש מסמן שדה ובוחר את שם התווית שלו, התווית מודגשת בצהוב.

## באילו כלים היא משתתפת?
**Mapper v3** - בזמן מיפוי שדות.

## מי קורא לה?
- `MapperCore.js` / `OverlayRenderer.js` - הפעלת תצוגת תוויות
- `WordSelector.js` - בחירת מילים מעדכנת את התוויות

## מתי היא פעילה?
כשמצב תוויות מופעל ויש שדות עם תוויות מוגדרות.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `LabelOverlay.js` | **רינדור תוויות** - מציג אוברליי צהוב מעל טקסט תווית. תומך במצב עריכה (הרחבה/כיווץ). Singleton: `labelOverlay` |
