# תשתית משותפת - Core

## מה התיקייה הזו עושה?
זוהי **שכבת התשתית** של כל הפרויקט. היא מספקת את השירותים הבסיסיים שכל המודולים צורכים:
ניהול מצב, מערכת אירועים, טעינת PDF, והמרת קואורדינטות.

## באילו כלים היא משתתפת?
- **Mapper v3** - משתמש ב-State, Events, PDF
- **LiveFill** - משתמש ב-State, Events, PDF
- **Fill Engine** - משתמש ב-State (בעקיפין)

## מי קורא לה?
כל המודולים שצריכים גישה למצב גלובלי, שליחת אירועים, טעינת PDF, או המרת קואורדינטות.

## מתי היא פעילה?
**תמיד** - מרגע טעינת האפליקציה ועד סגירתה.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `index.js` | נקודת כניסה - מייצא את כל מודולי הליבה |
| `UnifiedStateManager.js` | ניהול מצב גלובלי - שדות, ערכים, היסטוריה (undo/redo) |
| `UnifiedEventBus.js` | מערכת אירועים מרכזית - תקשורת בין מודולים. כולל מוניטור ביצועים ומצב חירום |
| `PDFService.js` | טעינה ורינדור PDF - תומך באסטרטגיות רינדור שונות (canvas/image), cache לדפים |
| `CoordinateService.js` | המרת קואורדינטות בין 4 מערכות: PDF נורמלי, PDF נקודות, מסך, CSS |

## ייצוא עיקרי
```javascript
import { state, eventBus, Events, PDFService, CoordinateService } from '../core/index.js';
```
