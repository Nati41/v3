# ממשק מילוי ללקוח - LiveFill

## מה התיקייה הזו עושה?
מספקת **ממשק פשוט ללקוח** למילוי טפסי PDF.
הלקוח מקבל טופס עם שדות מוגדרים מראש, ממלא את הפרטים שלו, ומייצא PDF סופי.

## באילו כלים היא משתתפת?
**LiveFill** - כלי עצמאי.

## מי קורא לה?
- `livefill.html` - נקודת כניסה
- `fill-engine.js` - מנוע מילוי (לייצוא)

## מתי היא פעילה?
כשלקוח פותח קישור לטופס (אחרי שהמקצוען מיפה אותו).

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `livefill.html` | **נקודת כניסה** - HTML ראשי |
| `livefill.css` | **עיצוב** |
| `js/main-livefill.js` | **אתחול** - טעינת PDF, תבנית, והפעלת ממשק |
| `js/livefill-core.js` | **ליבה** - לוגיקה ללא DOM: חישובי bbox, סגנונות ברירת מחדל, בניית נתוני שדה |
| `js/livefill-ui.js` | **ממשק** - רינדור שדות, קונסולת דיבאג, אינטראקציה |
| `js/data-store-manager.js` | **שמירת נתונים** - persistence של ערכי שדות |
| `js/field-input-popover.js` | **פופובר קלט** - חלון קלט שצץ ליד השדה |
| `js/export-engine.js` | **ייצוא** - יצירת PDF סופי מלא |
| `js/preview-text-renderer.js` | **תצוגה מקדימה** - רינדור חי של טקסט על ה-PDF |
| `fonts/DavidLibre-Regular.ttf` | **פונט עברי** |

## עיקרון עיצובי
> הקוד מפריד בין **ליבה ללא DOM** (`livefill-core.js`) לבין **ממשק עם DOM** (`livefill-ui.js`).
> זה מאפשר בדיקות יחידה על הלוגיקה בלי דפדפן.
