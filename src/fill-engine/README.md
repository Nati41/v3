# מנוע מילוי PDF - Fill Engine

## מה התיקייה הזו עושה?
**ממלא טפסי PDF בנתונים.** מקבל תבנית מיפוי (JSON) + נתוני לקוח,
ומייצר PDF מלא מוכן להגשה.

## באילו כלים היא משתתפת?
- **Mapper v3** - ייצוא וסימולציית מילוי
- **LiveFill** - מילוי בפועל
- **Mobile Fill** - מילוי מנייד

## מי קורא לה?
- `FillEngineExporter.js` (Mapper) - ייצוא תבנית
- `livefill-core.js` (LiveFill) - מילוי PDF
- `export-controller.js` (Mobile) - ייצוא סופי

## מתי היא פעילה?
בכל פעולת מילוי או ייצוא PDF.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `fill-engine.js` | **מנוע מילוי ראשי** - טקסט (RTL), צ'קבוקס, רדיו, טבלאות, חתימות. סקיילינג אוטומטי, חיתוך, גלישת שורות. דיאגנוסטיקה מלאה |
| `fill-engine-ui.js` | **ממשק** - כפתור ייצוא, סימולציית מילוי חי, תצוגת דיאגנוסטיקה |
| `ExcelFillUI.js` | **ממשק אקסל** - ייבוא נתונים מאקסל/CSV |
| `ExcelDataResolver.js` | **פרסור אקסל** - קריאת נתונים עם אסטרטגיית התאמה רב-שכבתית |
| `TableDataAdapter.js` | **מתאם טבלאות** - התאמת נתוני טבלה לפורמט המנוע |
| `font-manager.js` | **ניהול פונטים** - טעינת David Libre ופונטים נוספים לעברית |
