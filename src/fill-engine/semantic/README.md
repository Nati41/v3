# התאמה סמנטית חכמה - Semantic Matching

## מה התיקייה הזו עושה?
מבצעת **התאמה חכמה** בין שמות שדות בתבנית לנתונים שמגיעים מאקסל, ידני, או AI.
גם אם השם שונה ("שם משפחה" ← "שם_משפחה" ← "last name") - המנוע מזהה שזה אותו שדה.

## באילו כלים היא משתתפת?
**Fill Engine** - בכל פעולת מילוי.

## מי קורא לה?
- `fill-engine.js` - לפני מילוי, מפעיל התאמה סמנטית
- `ExcelDataResolver.js` - התאמת עמודות אקסל לשדות

## מתי היא פעילה?
בכל מילוי PDF - אוטומטית.

## קבצים מרכזיים

| קובץ | תפקיד |
|------|--------|
| `SemanticMatcher.js` | **מנוע התאמה** - 5 שכבות: (1) התאמה מדויקת, (2) מילון נרדפות, (3) התאמה מעורפלת (Levenshtein), (4) פורמט, (5) הקשר ישות |
| `SemanticIntegration.js` | **שכבת אינטגרציה** - מחבר את המנוע לשאר המערכת |
| `Preprocessor.js` | **עיבוד מקדים** - נירמול כותרות (רווחים, קיצורים, אותיות) |
| `MultiValueParser.js` | **ערכים מרובים** - פירוק שדה שמכיל כמה ערכים (למשל "שם מלא" → שם פרטי + משפחה) |
| `ValueHelpers.js` | **עוזרי ערכים** - המרות (תאריכים, טלפונים, ת.ז.) |
| `CanonicalCategories.js` | **קטגוריות** - קיבוץ שמות קנוניים לפי תחום (אישי, כתובת, תעסוקה, משכורת) |
| `index.js` | נקודת כניסה |

## 5 שכבות ההתאמה (Tiers)

| שכבה | שיטה | ביטחון |
|------|-------|--------|
| 1 | התאמה מדויקת (case-insensitive) | 1.0 |
| 2 | מילון נרדפות (synonym) | 0.95 |
| 3 | התאמה מעורפלת (Levenshtein distance) | 0.70-0.85 |
| 4 | זיהוי לפי פורמט (ת.ז., טלפון, תאריך) | 0.60 |
| 5 | הקשר ישות (disambiguation) | 0.50+ |
